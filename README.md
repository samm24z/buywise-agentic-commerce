# BuyWise — AI-Powered Purchase Decision & Agentic Checkout

An intelligent agentic commerce assistant that helps users make informed purchasing decisions and seamlessly executes checkouts.

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **Backend**: Python, FastAPI
- **AI & Intelligence**: Gemini API
- **Payments**: Razorpay (Test Mode)

## Project Goal

To simplify online shopping through AI-driven product comparison, personalized purchase recommendations, and autonomous checkout flows powered by Razorpay.
